## 这东西是怎么来的

我是昆山小孩。从小到大，每天上学放学，妈妈车里永远是 FM101.7。具体放的是哪个节目早记不清了，
反正车一发动就是动感101，换台？不存在的。这么多年下来，这个频率大概已经刻进基因里了。

后来出国了，几年过去，人在纽约，口味一点没变，还是好这一口。但问题来了：

- 网上只有**直播**。
- 纽约早上七点，上海已经晚上七点。我想听的是早高峰那个精神抖擞的电台，听到的却是人家下班后的温柔夜话。
- 想在上学的钟点听上学时的节目？那得凌晨爬起来。

试过几次我想通了：电台是不会为我改作息的，那就让服务器替我改。
把上海的广播录下来，等十二个小时，在同一个钟点原样放给我。妈妈车里的那套作息，整套搬到纽约。

顺便造福一下全世界各地和我一样想家的 101 听众。如果有的话。

## 它是怎么做到的

说穿了没有任何魔法，就是「录下来，晚点放」：

- 一台便宜的小服务器 24 小时守着直播流，按分钟切成小段 MP3 存起来，只留最近 48 小时，不占地方。
- 你的手机打开页面时带上自己的时区，服务器算一下「上海的钟点 = 你的钟点」是哪一刻，
  从那一刻的录音开始按正常速度推给你，锁屏也继续放。
- 纽约比上海晚 12 或 13 小时，所以你要听的那段永远早就录好了。要是你人在上海或者更东边，
  没有录音可以「提前」，页面会老老实实切成直播并告诉你。
- 整个项目就一个 Python 文件，只用标准库：没有 ffmpeg，没有数据库，没有 pip install，内存 20MB。
  它干的事本质上就是把网络上的字节写进文件，再从文件里读出来。

## 都有什么

- 「按我的时间 / 上海直播」一键切换，想念上海的夜晚也可以直接听直播。
- 节目卡片：正在播的节目、主播、进度条，还有接下来是谁。节目单来自蜻蜓FM 的工作日节目表，周末可能对不上，电台改版了也得手动改。
- 时差模式下可以「−30 秒 / 回到节目开头 / +30 秒」，锁屏上的快进快退键也能用，锁屏上显示的是「上海几点的节目」。
- 定时关闭：15 / 30 / 60 / 90 分钟，睡前听最合适。
- 分享给朋友：发个链接，朋友按各自手机的时区听，温哥华的朋友听温哥华的 7 点。
- 底部显示录制状态、已存多少小时、几个人在听。这个数通常是 1。
- 背景是 30 张上海和昆山的风景照：外滩、陆家嘴、豫园、朱家角、武康路的梧桐，当然还有周庄和千灯。
  全部来自 Wikimedia Commons 自由许可，页面底下署名，清单在 `photos/CREDITS.md`。
  照片配天气：霓虹光斑、萤火、阳光里的尘埃、雨和闪电、樱花、落叶、雪，还有一个 WebGL 极光。
  默认随机轮播，每 30 秒换一张，也可以用「背景」按钮固定一个。
- 卡片是透明玻璃。放着不碰屏幕 7 秒，整个界面淡下去露出照片，碰一下就回来。
- 添加到主屏幕，图标就是台标，看起来像个正经 App。

## 自己搭一个

想听别的电台，或者单纯不想用别人的服务器，自己搭很简单。

### 云服务器（推荐）

1. 开一台 Ubuntu 24.04 的小服务器。DigitalOcean 最便宜的 Basic 套餐，每月 4 美元，512MB 内存，够用。地区选离你近的。
2. 认证方式选 SSH Key。脚本默认用 `~/.ssh/radio1017_ed25519` 这把钥匙，没有就生成一把：
   `ssh-keygen -t ed25519 -f ~/.ssh/radio1017_ed25519`，把 `.pub` 文件的内容贴到服务器后台。
   想用别的钥匙：`RADIO_SSH_KEY=~/.ssh/id_ed25519 ./deploy.sh ...`。
3. 在这个文件夹里跑：

```bash
./deploy.sh <服务器IP> America/New_York
```

第二个参数是「我的时间」用哪个时区。脚本会装好 systemd 服务和 Caddy，自动申请 https 证书，开防火墙，
最后打印手机要用的地址，形如 `https://1-2-3-4.sslip.io/密钥/`。地址里带一段随机密钥，不知道的人打不开。
以后改了代码再跑一次同样的命令，密钥不变；想换密钥让旧链接作废，加第三个参数。

手机用 Safari 打开地址，「分享 → 添加到主屏幕」，完事。

### 家里的 Mac

不想租服务器，也可以让家里的 Mac 录：

```bash
./install.sh
```

装成开机自启的后台服务，程序和录音在 `~/Library/Application Support/radio1017`，装完会打印手机要打开的地址
（手机和 Mac 连同一个 Wi‑Fi）。出门在外想听，装个 Tailscale，用 Mac 的 Tailscale 地址加 `:8017`。
Mac 要开着且联网才能录；`install.sh` 用 `caffeinate` 挡住了闲置睡眠，合盖会停。
停掉：`./uninstall.sh`；连录音一起删：`./uninstall.sh --purge`。

也可以直接跑 `python3 radio1017.py`，页面在 http://localhost:8017 。环境变量：`RADIO_PORT`、`RADIO_BIND`、
`RADIO_KEY`（地址前缀密钥）、`RADIO_LOCAL_TZ`（「我的时间」的时区，不设就用系统时区）、`RADIO_DATA`（录音目录）。

### 占用

- 内存约 20MB，CPU 几乎为零。
- 录音只留最近 48 小时，约 1.4GB。想多留，改 `radio1017.py` 开头的 `RETAIN_HOURS`。
- 每个听众 64kbps，最便宜的服务器几十个人同时听没问题。到那天我再考虑升级。

## 换一个电台

如果你不是上海小孩，是别的城市的小孩：`radio1017.py` 开头的 `STREAMS` 是直播流地址，`STATION_TZ` 是电台所在时区，
网页里的 `SCHEDULE` 是节目单，台标在 `LOGO_B64` / `ICON_B64`。换掉这几处，你也可以在地球另一边按点听家乡的电台。
