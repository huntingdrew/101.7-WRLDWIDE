# 动感101 时差回放

中文 · [English](README.en.md)

在纽约早上 7 点打开，听到的就是上海早上 7 点的《动感101》。

服务器 24 小时录上海动感101（FM101.7）的直播流，手机打开网页时按你本地的钟点回放：你这边几点，就放上海几点的节目。
一个 Python 文件，只用标准库，每月 4 美元的小服务器就够跑。

## 原理

- 服务器持续拉直播流，按分钟切成小段 MP3 存起来，只留最近 48 小时。
- 手机打开页面时带上自己的时区，服务器找到「上海的钟点 = 你的钟点」那一刻的录音，按实际速度推给你，锁屏也继续放。
- 纽约比上海晚 12 或 13 小时，所以你要听的那段总是早就录好了。人在上海或更东边的时区没有提前量，页面自动切成直播并提示。
- 没有 ffmpeg，没有数据库，没有第三方依赖，内存约 20MB。

## 功能

- 「按我的时间 / 上海直播」一键切换。
- 节目卡片：正在播的节目、主播、进度，和接下来的节目（节目单来自蜻蜓FM 工作日节目表，周末可能不同）。
- 时差模式下有「−30 秒 / 节目开头 / +30 秒」，锁屏上的快进快退键也能用；锁屏显示的是上海几点的节目。
- 定时关闭：15 / 30 / 60 / 90 分钟。
- 分享给朋友：系统分享面板发链接，朋友按各自手机的时区听。
- 底部显示录制状态、已存时长和在线人数（按设备去重）。
- 背景：30 张上海和昆山的风景照（外滩、陆家嘴、豫园、朱家角、武康路、周庄、千灯……），都来自 Wikimedia Commons 自由许可，
  署名显示在页面底部，清单见 `photos/CREDITS.md`。配天气动画：霓虹光斑、萤火、阳光尘埃、雨和闪电、樱花、梧桐落叶、雪，
  还有一个 WebGL 极光。默认随机轮播，每 30 秒换一张，「背景」按钮可以固定场景。
- 透明玻璃卡片；播放中 7 秒不碰屏幕，界面淡到 16% 露出照片，碰一下就回来。
- 添加到主屏幕，图标就是台标。

## 部署到云服务器（推荐）

1. 开一台 Ubuntu 24.04 的小服务器（DigitalOcean 最便宜的 Basic 套餐，每月 4 美元，512MB 内存就够），地区选离你近的。
2. 认证方式选 SSH Key。脚本默认用 `~/.ssh/radio1017_ed25519` 这把钥匙，没有就生成一把：
   `ssh-keygen -t ed25519 -f ~/.ssh/radio1017_ed25519`，把 `.pub` 文件的内容贴到服务器后台。
   想用别的钥匙：`RADIO_SSH_KEY=~/.ssh/id_ed25519 ./deploy.sh ...`。
3. 在这个文件夹里运行：

```bash
./deploy.sh <服务器IP> America/New_York
```

第二个参数是「我的时间」用哪个时区。脚本会装好 systemd 服务和 Caddy，自动申请 https 证书，开防火墙，
最后打印手机要用的地址，形如 `https://1-2-3-4.sslip.io/密钥/`。地址里带一段随机密钥，不知道的人打不开。
以后改了代码再跑一次同样的命令，密钥不变；想换密钥让旧链接作废，加第三个参数。

手机用 Safari 打开地址，「分享 → 添加到主屏幕」。

## 在 Mac 上跑

不想租服务器，也可以让家里的 Mac 录：

```bash
./install.sh
```

装成开机自启的后台服务，程序和录音在 `~/Library/Application Support/radio1017`，装完会打印手机要打开的地址
（手机和 Mac 连同一个 Wi‑Fi）。出门在外想听，装个 Tailscale，用 Mac 的 Tailscale 地址加 `:8017`。
Mac 要开着且联网才能录；`install.sh` 用 `caffeinate` 挡住了闲置睡眠，合盖会停。
停掉：`./uninstall.sh`；连录音一起删：`./uninstall.sh --purge`。

也可以直接跑 `python3 radio1017.py`，页面在 http://localhost:8017 。环境变量：`RADIO_PORT`、`RADIO_BIND`、
`RADIO_KEY`（地址前缀密钥）、`RADIO_LOCAL_TZ`（「我的时间」的时区，不设就用系统时区）、`RADIO_DATA`（录音目录）。

## 占用

- 内存约 20MB，CPU 几乎为零，就是把网络字节写进文件。
- 录音只留最近 48 小时，约 1.4GB。想改，改 `radio1017.py` 开头的 `RETAIN_HOURS`。
- 每个听众 64kbps，最便宜的服务器几十个人同时听没问题。

## 换一个电台

`radio1017.py` 开头的 `STREAMS` 是直播流地址，`STATION_TZ` 是电台所在时区，网页里的 `SCHEDULE` 是节目单，
台标在 `LOGO_B64` / `ICON_B64`。换掉这几处就能回放别的电台。
